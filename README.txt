V8.1 修正
---------
【モブくんキャッチャー】
- 取得数だけを表示する疑似的な処理を廃止。
- STOPした瞬間のクレーン位置・高さ・アーム幅から、実際にアームの内側へ入っている人形だけを判定。
- 掴んだ人形は床から消え、クレーンヘッドの下へ実際に表示。
- クレーン上昇・横移動と一緒に掴んだ人形も移動。
- 落とし口でアームが開くと、掴んだ人形が実際に落下する演出。
- 悪い位置なら0体もあり、通常は数体。中央の密集部を高さ・開き幅まで上手く合わせた場合のみ8～10体を狙える。

【モブくん危機一髪】
- 3レーン縦並びを廃止。
- 3体を横一列に配置。
- 長縄のような1本の縦長エネルギーが横から横切る方式へ変更。
- 3体それぞれをエネルギー通過のタイミングでタップしてジャンプ。
- 全員回避で1回成功。成功するほど速度アップ。

【モブくん人形大人気】
- 人形がすでに入った箱でもMOB DOLLを持てるよう変更。
- その状態で箱へ追加投入すると「2体入り不良品」扱い。
- NGスタンプ、箱のシェイク、DISCARDゴミ箱へ飛んでいく破棄演出を追加。
- 破棄箱は完成数に加算されない。


V8.1 catcher final adjustment
-----------------------------
- 掴んだように見せる複製表示ではなく、床に置かれていた実物のDOMフィギュアそのものをクレーン内部へ移動する方式に変更。
- 掴まれたフィギュアは床から本当に消え、クレーンと一緒に上昇・横移動・落下します。
