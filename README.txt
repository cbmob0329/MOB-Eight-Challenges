MOB PARTY GAMES V6
===================

今回の修正

GAME 3 ナンバー12
- 4×3のコンパクト配置。
- 画面開始時に自動で上端へ戻す。
- NEXTの数字以外はdisabledで入力不可。
- 12を先に押しても一切反応しない。
- 間違い操作で内部状態が止まる処理を廃止。
- 正しい数字を押した時だけ次へ進む。

長押し・画像コピー・選択ロック
- contextmenu / dragstart / selectstart / copy / cut を無効化。
- -webkit-touch-callout:none。
- user-select:none。
- ダブルタップ・ピンチズーム抑止を継続。
- グラグラモブくんの操作フィギュアはimgではなくCSS背景DIVに変更。

GAME 5 グラグラモブくん
- 成否は実際の横方向の重なり率だけで決定。
- 必要重なり以上なら必ず乗る。
- 重なり不足なら必ず落ちる。
- ランダム落下なし。
- 5体目からタワーのグラグラが強くなる。
- 掴んでいるフィギュアもグラグラ。
- BALANCEメーター。
- PERFECT / GOOD / SAFE / BALANCE BREAK 演出。

NEW GAME 6 頑張れモブくん
- 10秒の左右2択。
- 片方を選ぶと左右両方変更。
- 獲得済み項目は再登場しない。
- ランク・罠は選択中は非表示。
- 途中で選択を止めて待つのも可能。
- 10秒後、世界パワームーブ大会へ。
- WORLD RANKING 1～40位を表示しMOBを強調。
- アメリカ、日本、ロシア、ウクライナ、韓国、フランス、ドイツ、ベネズエラは上位に来やすい。
- S/A補正は小さめ。S/Aなしでも上位・1位の可能性あり。
- 最後に「モブくんは国を背負って戦い、〇位という成績を収めた」。
