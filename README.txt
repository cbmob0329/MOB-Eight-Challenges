MOB PARTY GAMES V7
===================

主な変更

GAME 6 を「1990世界大会」へ変更
- 10秒の左右2択。
- 毎回必ず片方は1990。両方罠・進行不能なし。
- 1990を押すと1周。
- 5回連続で1990を押すごとにBONUS +1周。
- 一部のニセ項目は罠で-1周。
- ニセを押すと連続数はリセット。
- 1991 / 1989 / 2000 / 1909 / 1999 等の似た項目が登場。
- 最終周回数をもとに世界1～40位を決定。
- 最後に「モブくんは世界大会で1990を○周披露し、○位という成績を収めた。」

NEW MODE 05「100点 スコアバトル」
- プレイヤー4人。
- ゲーム順位ポイントではなく各ゲーム0～100点。
- 6ゲーム合計最大600点で最終順位。

スコア換算
1. 反射神経
   0.150秒以下=100点 / 0.300秒=50点 / 0.500秒以上=0点。間は線形補間。
2. 記憶力
   正解数×10点。
3. ナンバー12
   4.00秒=100点 / 12.00秒以上=0点。間は線形補間。
4. フィギュア飛ばし
   2000m=100点 / 0m=0点。
5. グラグラモブくん
   30体以上=100点 / 0体=0点。
6. 1990世界大会
   世界1位=100点 / 40位=0点。

- 横ゲージを高速化。
- 最大2000mへ変更。
- パワー差が飛距離に出やすい非線形カーブへ変更。

グラグラモブくん
- 時間経過でWINDが0～100%へ上昇し、揺れが強くなる。
- フィギュアを短くタップ：DROP ×1→×2→×3→×1。
- 横へ動かす：掴む。
- 離す：1～3体を同時DROP。
- 序盤の必要重なり率を低くし、10体前後まではかなり到達しやすく調整。
- 成否は実際の重なり率で決定。ランダム落下なし。
- 崩壊時はカメラが一番下まで戻りながらタワー崩壊を追う。

CPU

- 飛ばしは最大2000m基準、グラグラは新難易度基準に更新。

V7.1 修正
---------
【グラグラモブくん】
- 掴めなかった原因を修正。
  active-layer が pointer-events:none なのに、操作用 stack-bundle に
  pointer-events:auto が無かったため、タッチがフィギュアを通り抜けていました。
- 操作フィギュアを確実にタッチ対象化。
- 3px以上動かすと即GRAB。
- 動かさなくても0.22秒ホールドするとGRAB。
- 短いタップだけは DROP ×1 → ×2 → ×3 の切り替え。
- iPhone Safariの長押しメニュー、画像コピー、文字選択、ドラッグを
  グラグラゲーム領域でさらに強く禁止。
- touchstart / contextmenu もゲーム領域で preventDefault。
- 掴んだ状態のグラグラ演出は継続。

【1990世界大会】
- 20周で20位前後になりやすかった世界順位バランスを緩和。
- 目安:
  15周 = 中位～上位
  20周 = 上位候補
  25周 = 表彰台候補
  30周前後 = 優勝候補
- 完全固定順位ではなく毎回多少変動します。


V7.2 1990世界大会バランス
-------------------------
- 1990を25周以上披露した場合は世界1位・優勝を確定。
- 20～24周は世界上位～表彰台候補。
- 24周以下は毎回多少順位が変動。
