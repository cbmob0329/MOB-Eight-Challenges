フィギュア飛ばし V8
- 横ゲージの両端約10%を「？」フィルターで隠す

- 横ゲージ速度も少しランダム化
- 最大2000m

グラグラモブくん V8
- 3体同時DROPを完全撤廃
- 常に1体ずつ
- 制限時間10秒
- 時間経過で風が0→100%へ強化
- 置き場所を示すガイド・BALANCEゲージを撤廃
- 掴んでいるフィギュアも風で揺れる
- 崩れた時はカメラが一番下へ戻って崩壊を追う
- 10体前後には到達しやすいが後半ほど難しくなる

NEW: モブくん危機一髪
- 3レーン
- 3体それぞれをタップして回避
- 3体全員回避で1回成功
- 成功するたびエネルギー高速化
- 1体でも被弾で終了

NEW: モブくん人形大人気
- 10秒
- MOB箱がベルトコンベアを流れる
- 空箱は 人形タップ→箱→箱で封印
- 最初から人形入り箱は箱1タップで完成
- 状態はランダム

NEW: モブくんキャッチャー
- 1回勝負のUFOキャッチャー
- 左右矢印で位置
- 降下
- アーム幅が動く
- STOPで高さとアーム幅を決定
- 自動CLOSE→持ち上げ→落とし口へ移動→OPEN
- 最大10体
