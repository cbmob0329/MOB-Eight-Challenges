V8.1 修正
---------
【モブくんキャッチャー】
- 取得数だけを表示する疑似的な処理を廃止。
- STOPした瞬間のクレーン位置・高さ・アーム幅から、実際にアームの内側へ入っている人形だけを判定。
- 掴んだ人形は床から消え、クレーンヘッドの下へ実際に表示。
- クレーン上昇・横移動と一緒に掴んだ人形も移動。
- 落とし口でアームが開くと、掴んだ人形が実際に落下する演出。
- 悪い位置なら0体もあり、通常は数体。中央の密集部を高さ・開き幅まで上手く合わせた場合のみ8～10体を狙える。

【モブくん危機一髪】
- 3レーン縦並びを廃止。
- 3体を横一列に配置。
- 長縄のような1本の縦長エネルギーが横から横切る方式へ変更。
- 3体それぞれをエネルギー通過のタイミングでタップしてジャンプ。
- 全員回避で1回成功。成功するほど速度アップ。

【モブくん人形大人気】
- 人形がすでに入った箱でもMOB DOLLを持てるよう変更。
- その状態で箱へ追加投入すると「2体入り不良品」扱い。
- NGスタンプ、箱のシェイク、DISCARDゴミ箱へ飛んでいく破棄演出を追加。
- 破棄箱は完成数に加算されない。


V8.1 catcher final adjustment
-----------------------------
- 掴んだように見せる複製表示ではなく、床に置かれていた実物のDOMフィギュアそのものをクレーン内部へ移動する方式に変更。
- 掴まれたフィギュアは床から本当に消え、クレーンと一緒に上昇・横移動・落下します。


V8.2 修正
---------
【モブくんキャッチャー】
- 見た目をUFOキャッチャー筐体として作り直し。
- 黄色いMOB CATCHER看板、ガラス筐体、左右支柱、上部レール、台車、ケーブル、
  クレーンヘッド、2本アーム、景品床、PRIZE落とし口を追加。
- アーム幅は降下前に「− / ＋」で28%～88%の範囲から自分で決定。
- 降下ボタンを押したらアーム幅は固定され、降下中には変化しない。
- STOPは高さだけを決定。
- STOP時、実際のDOM上のモブくん位置とアーム内部の範囲を比較して取得判定。
- 掴まれた実物のモブくんDOMを景品山からクレーン内へ移し、
  上昇・横移動・PRIZE落下まで同じ実物が動く。
- 狙いが悪ければ0体。幅・位置・高さが良ければ複数、最大10体。

【モブくん危機一髪】
- 縦長エネルギーを完全撤廃。
- モブくん3体を画面いっぱいに広く横一列配置。
- エネルギーは足元を走る短い横長エネルギー。
- 1本の同じエネルギーをP1→P2→P3が順番に1ジャンプで回避。
- エネルギーは画面外から助走して入ってくるので、開始直後即死になりにくい。
- 最初から速めだが、成功ごとにさらに高速化。

【グラグラモブくん】
- ステージ上部にNEXT MOB待機台を追加。
- icon/01.pngの待機モブくんを常時表示。
- GO後は同じ場所付近に操作可能なモブくんが明確に出現。


V8.3 追加・再調整
-----------------
【全ゲームの見切れ対策】
- 実際のプレイ中だけ gameplay-fit モードを使用。
- スマホの100dvhから上部バーとSafe Areaを差し引いてプレイ領域を固定。
- プレイ中はスクロール不要になるよう、各ゲームのヘッダー・HUD・ゲーム領域を個別に再調整。
- 反射神経 / 記憶力 / ナンバー12 / フィギュア飛ばし / グラグラ / 1990 /
  危機一髪 / 工場 / キャッチャー / 整理整頓 / スキージャンプを対象に調整。
- メニュー、ルール、結果画面は通常どおりスクロール可能。

【モブくんキャッチャー】
- アーム幅を最大にすれば良いだけのバランスを廃止。
- 28%～88%で降下前に幅を決める。
- 幅は約58～64%付近が保持力と包み込みのバランス帯。
- 広げすぎるとアーム内には多く入るが、閉じる時に端の景品が押し出されてこぼれる。
- 狭すぎると安定するが一度に囲える数が少ない。
- 高さも重要で、景品山へ深すぎても浅すぎても保持数が減る。
- STOP時の実DOM位置から判定し、掴んだ実物DOMをクレーン内へ移動。
- 0体も普通にあり、最大10体は位置・幅・深さが揃った時だけ。

【モブくん危機一髪】
- P1を画面中央寄りまで離し、P1/P2/P3をさらに広く配置。
- エネルギーは画面外 -220px から接近。
- 進入前にINCOMING予告を約0.65～0.92秒表示。
- 初速を250px/sへ調整し、成功ごとに24px/s加速、最大880px/s。
- エネルギーは44×12pxの短い足元エネルギー。
- 同じ1本を3体が順番に1ジャンプで回避。

【NEW GAME 10 モブくん整理整頓】
- 上部: 見本の部屋。
- 下部: 操作する部屋。
- 棚、テーブル、ラグ、箱を配置。
- 上の見本には10体のモブくん。
- 下は毎回ランダム位置から開始。
- 10秒間ドラッグ。
- 10体は同一キャラなので、終了時に10体同士の最小総距離になる組み合わせを計算して一致率を決定。
- 完全一致=100%。
- 目標の近くへ置くとスナップするので100%も可能。
- 100点スコアバトルでは一致率がそのまま点数。
- CPU通常 68～96%前後 / SUPER CPU 96～100%。

【NEW GAME 11 モブくんスキージャンプ】
- 3・2・1後、自動でジャンプ台を滑走。
- 理想の踏切時刻: スタートから1.820秒。
- 画面を1回タップした時刻との差で飛距離を決定。
- 最高240m。
- タイミング目安:
  PERFECT: ±45ms → 約229～240m
  GREAT: ±46～90ms → 約204～229m
  GOOD: ±91～160ms → 約155～204m
  それ以上のズレ → 約55～155m
- 押さずに踏切を大きく過ぎた場合は短いジャンプ。
- 100点モード:
  240m = 100点
  80m以下 = 0点
  80～240mは比例計算。
- CPU通常 約166～232m / SUPER CPU 約226～240m。


V8.4 変更
---------
【モブくん危機一髪】
- 初速 340px/s。
- 成功1回ごとに +70px/s。
- 最大 1800px/s。
- 予告は残しつつ、後半はかなり高速な3連続ジャンプが必要。

【モブくんキャッチャー】
- 景品をさらに下へ配置し、クレーンとの縦距離を拡大。
- アーム幅の「%」「説明文」を撤廃。
- アーム幅は横ゲージが自動往復し、ゲージをタップして停止した位置で決定。
- その後に左右移動 → 降下 → STOP。
- アーム幅を広げすぎた場合の保持力低下をさらに強化。
- 最大幅なら大量GET、という攻略は不可。
- 約中央幅でも位置・深さが悪いと0～少数。
- 実際にアーム内へ入り、閉じた後に保持できた実物モブくんだけが移動。

【モブくん整理整頓】
- 10体 → 7体。
- 見本7体の配置を毎回ランダム生成。
- 下の7体も毎回ランダム。
- 自動吸着 / スナップを完全撤廃。
- プレイヤーが置いた位置そのままで一致率計算。
- 同一キャラ7体なので、終了時は見本7点と操作7点の最小総距離になる対応を計算。

【モブくんスキージャンプ】
- スロープを長い1本のジャンプ台として描き直し。
- スタート台 → 長い下りスロープ → 黄色いJUMPリップを明示。
- 踏切後は最大1000mの長距離飛行。
- 飛行中はモブくんが画面内に残るようカメラが横追尾。
- 0 / 200 / 400 / 600 / 800 / 1000mの距離マーカー。
- 飛行アークを大きくし、FLY演出を追加。
- タイミング:
  PERFECT ±40ms : 約910～1000m
  GREAT ±41～85ms : 約764～910m
  GOOD ±86～155ms : 約523～764m
  それ以上 : 約110～523m
- 100点モード:
  200m以下 = 0点
  1000m = 100点
  200～1000mは比例計算。
- CPU:
  通常 約580～960m
  SUPER 約925～1000m

【NEW GAME 12 モブくんスロット】
- 1000コインスタート。
- 1回100コイン。
- 10秒。
- シンボル: M / O / B / モブくん。

- 3リールを自分で1つずつ停止。
- 1リール目: 隠し狙いパターンへ82%で補助。

- 100点モード:
  1000コイン以下 = 0点

  3000コイン以上 = 100点

V8.6 修正
---------
【モブくんスキージャンプ】
- V8.5では距離計算自体はタップ時刻との差を使っていたが、
  見た目の黄色いJUMPリップと理想時刻が完全一致していなかった。
- V8.6では黄色いJUMPリップ到達時刻そのものを idealTime=2500ms に統一。
- モブくんの中心が黄色いJUMPリップへ到達する瞬間が最高タイミング。
- 有効ジャンプ受付:
  約180ms早い位置 ～ 約165ms遅い位置。
- それより早い場所で押してもジャンプしない。NOT YET表示のみで滑走継続。
- 踏切を過ぎて押した場合はジャンプせず落下。
- 何も押さなかった場合も踏切から落下して0m。
- タイミング差による距離:
  ±25ms: 約955～1000m
  ±26～55ms: 約850～955m
  ±56～95ms: 約670～850m
  ±96～135ms: 約460～670m
  ±136～180ms前後: 約220～460m
- 踏切失敗: 0m。
- 早押し連打で途中から飛ぶことはできない。

【モブくんキャッチャー】
- 景品配置を4つの山＋ばらけた景品へ変更。
- クレーン位置によって実際にアーム下へ存在する景品数が変わる。
- アーム取得判定をDOM上の見た目に依存する固定的な数ではなく、
  保存している各景品の実座標とクレーン中心・深さ・アーム幅から楕円範囲で計算。
- 密集地点を狙えば候補が多く、山と山の間では0～少数になる。
- 広い幅ほど取得範囲と最大容量は増える。
- 降下が浅い/深い場合は取得数が大きく減り、極端なら0体。
- 最大取得数は10体だが、固定7体になる処理は存在しない。
