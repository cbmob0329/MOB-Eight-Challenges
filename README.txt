MOB PARTY GAMES V5
===================

モード
1. 4人個人戦
2. 8人個人戦（プレイヤー4人 + CPU4人）
3. 2対2タッグ
4. プレイヤー4人 VS CPU4人
+ メインメニューから好きなゲームを1人で遊べる FREE PLAY

全5ゲーム

GAME 1 反射神経
- READY? → 3 → 2 → 1 → ランダム待機 → MOB
- MOB表示からタップまでを0.001秒単位で表示・記録
- 速い順に順位

GAME 2 記憶力
- icon/01.png ～ icon/10.png
- 10枚をランダム配置
- 光った順番にタップ
- 間違えた時点で記録終了

GAME 3 ナンバー12 パズル
- 12個のマス
- 1～12を毎回ランダムに配置
- 3 → 2 → 1 のあと計測開始
- 1 → 2 → ... → 12 の順番に押すとマスが消える
- 最後の12を消した瞬間のタイム
- icon/006.png を12分割背景として薄く使用

GAME 4 フィギュア飛ばし
- icon/01.png を使用
- 横長ゲージ + 円形ゲージ
- 2ゲージ平均で飛距離決定
- 最大1000m
- カメラ追尾 + 回転飛行 + リアルタイム距離表示

GAME 5 グラグラモブくん
- icon/01.png のフィギュアを何体積めるか競う
- フィギュアをタップしたまま左右移動
- 指を離すと落下
- 5体目あたりからタワーがグラグラし始め、許容範囲も狭くなる
- バランスを崩した時点の積み数を記録

CPU
- 通常CPUも強め
- ゲームごとにSUPER CPU抽選
- SUPER CPU時はかなり強い記録
- 抽選率はゲームごとに約10～16%
- CPUは待ち時間を省略して高速処理
